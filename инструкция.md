# Инструкция по использования нейросети
1. установите в терминале зависимости: pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
pip install Pillow flask watchdog
2. скачайте готовую модель нейросети в по ссылке в README файле и укажите её путь вместо моего в переменной MODEL_PATH
3. запустите код и перейдите по одной из ссылок.
